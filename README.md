# PRINCE BOOKS

Android book reader: import PDF, EPUB, TXT books; read offline, listen using Android text-to-speech, browse legal free-book sources, and practise ethical sales conversations.

This source repository is public and contains no personal credentials or copyrighted books.

## Getting the APK
Open **Actions → Build PRINCE BOOKS APK**, then download the `PRINCE-BOOKS-APK` artifact after a successful run. Extract the artifact ZIP to find `app-debug.apk` and install it on an Android device. Enable installations from the source app only if you trust this build.
